# 0001: Files are the contract between skills

Status: accepted, 2026-10-09

## Context

The skills must run on several coding agents, and a novel outlives many
sessions. Sub-agents and parallel execution exist on some agents and not on
others. A conversation is lost when the session ends; the novel project is
not.

## Decision

Skills communicate only through files in the novel project:

- `NOVEL.md`, the novel config;
- `manuscript/`, the chapters;
- `bible/`, the canon outside the text;
- `.continuity/facts/` and `.continuity/findings/`, generated by
  `check-continuity`;
- `.proofread/`, generated by `proofread`;
- `notes/ideas/`, written by `brainstorm`.

A skill reads the files it needs and writes its own. Sub-agents are an
accelerator: each skill has a path without them.

## Consequences

- A long novel can be checked in several sessions with the same result.
- Fact extracts are cached per chapter and only redone when the chapter
  changes, which is what makes a full-novel check affordable.
- The file formats are a public interface: changing one is a breaking change
  and goes in the changelog.
